👋 แนะนำแอปพลิเคชัน

EM CMU Calculator เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อช่วยอำนวยความสะดวกในการคำนวณขนาดยา อุปกรณ์ทางการแพทย์ และค่าทางคลินิกที่สำคัญ สำหรับผู้ป่วยฉุกเฉิน โดยเฉพาะอย่างยิ่งผู้ป่วยเด็ก

เหมาะสำหรับ: แพทย์เวชศาสตร์ฉุกเฉิน, กุมารแพทย์, แพทย์ประจำบ้าน, นักศึกษาแพทย์ และบุคลากรทางการแพทย์ที่ต้องดูแลผู้ป่วยในภาวะวิกฤตหรือฉุกเฉิน ที่ต้องการความรวดเร็วและแม่นยำในการเข้าถึงข้อมูล

🚀 การเริ่มต้นใช้งาน (How to start)

เมื่อเปิดแอปพลิเคชันขึ้นมา คุณจะพบกับหน้า Welcome Page ซึ่งออกแบบมาให้กรอกข้อมูลผู้ป่วยเบื้องต้น เพื่อให้แอปนำไปตั้งค่าระบบทั้งหมดโดยอัตโนมัติ

  1. กรอกข้อมูลพื้นฐาน: เพศ, อายุ (ปี, เดือน), น้ำหนัก (kg), และส่วนสูง (cm)
  2. การคำนวณอัตโนมัติ: ทันทีที่คุณกดปุ่ม Start Calculation ระบบจะดึงข้อมูลทั้งหมดไปใส่ในแผงข้อมูลผู้ป่วยด้านบน (Patient Panel) ทันที
  3. ระบบจะประเมิน น้ำหนักที่เหมาะสมที่สุด (Weight for Calculation) และนำไปคำนวณขนาดยาทุกชนิดในแอปโดยอัตโนมัติ
  4. หมายเหตุ: หากยังไม่มีข้อมูลผู้ป่วย สามารถกดปุ่ม Start Calculation เพื่อข้ามเข้าไปดูขนาดยามาตรฐานหรือรายชื่อยาก่อนได้เลย

✨ ความสามารถหลัก (Features)

⚖️

Weight for Calculation

ระบบจะคำนวณ TBW (น้ำหนักจริง), IBW (น้ำหนักอุดมคติตามส่วนสูง), และ LBW (น้ำหนักมวลกายไร้ไขมัน) ให้อัตโนมัติ โดยคุณสามารถกดเลือกสลับน้ำหนักที่จะใช้คำนวณยาได้ง่ายๆ ด้วยปุ่มสลับโหมด ระบบจะทำการคำนวณขนาดยาทั้งแอปใหม่ทันที

💊

Drug Categories

แบ่งหมวดหมู่ยาชัดเจน เข้าถึงง่ายตามสถานการณ์ทางคลินิก:

  • Pediatric EM: ยาฉุกเฉินสำหรับเด็ก
  • Neonatal: ยาและสารน้ำสำหรับทารกแรกเกิด
  • RSI / Post-Intubation: ยาสำหรับการใส่ท่อช่วยหายใจ
  • Adult: ขนาดยาฉุกเฉินสำหรับผู้ใหญ่ (Neuro, Cardio ฯลฯ)

🔍

Smart Search

ช่องค้นหาที่ด้านบนของหมวดหมู่ยา สามารถพิมพ์ชื่อยาเพื่อค้นหาข้ามกลุ่มย่อยได้ทันที ระบบจะเลื่อนหน้าจอ (Scroll) ไปยังตำแหน่งของยานั้นๆ โดยอัตโนมัติ ทำให้ไม่ต้องเสียเวลาเลื่อนหาด้วยตัวเอง

📂

Collapsible Cards

หมวดหมู่ยาและกลุ่มยาต่างๆ สามารถ คลิกเพื่อพับเก็บหรือกางออกได้ (Collapse/Expand) ช่วยจัดระเบียบหน้าจอให้สะอาดตา และโฟกัสเฉพาะกลุ่มยาที่กำลังสนใจได้ง่ายขึ้น

🧰

Equipment Sizing

ในหมวด PALS ระบบจะคำนวณขนาดอุปกรณ์ที่เหมาะสมสำหรับเด็ก (เช่น ETT, LMA, Blade, Chest Tube, Foley) ทันทีที่กรอกอายุหรือน้ำหนัก หากยังไม่กรอกข้อมูล ระบบจะแสดงรายการอุปกรณ์รอไว้ล่วงหน้า

🧮

Manual Calculator

เครื่องคิดเลขคำนวณยาแบบอิสระ เหมาะสำหรับกรณีที่ต้องการปรับ Dose ยาเอง โดยสามารถระบุ ขนาดยาเป้าหมาย (Dose), น้ำหนัก (Wt), และความเข้มข้นของยา (Conc) ระบบจะคำนวณปริมาตรสุทธิ (Volume) ออกมาให้ทันที

💓

Pediatric Reference V/S

ระบบแสดงตารางค่าสัญญาณชีพปกติของเด็ก (Normal Vital Signs) และเกณฑ์ความดันโลหิตต่ำ (Hypotension limits) แบ่งตามช่วงอายุอย่างละเอียด ช่วยให้แพทย์ประเมินความรุนแรงของอาการผู้ป่วยได้รวดเร็วขึ้น
